# Baseline - PDF RAG Chatbot

This folder contains the original native PDF RAG Chatbot implementation used as the reference version for the AIO 2026 Learning Assistant project.

## Purpose

- Preserve the assignment-style baseline.
- Demo the initial PDF RAG flow.
- Compare limitations against the improved `upgrade/` version.

## Run

```bash
streamlit run baseline/chatbot_app_native.py
```

## Rules

- Treat this folder as reference-only unless a Task ID explicitly targets baseline.
- Do not add upgrade features here.
- Technical improvements should be implemented in `upgrade/`.
