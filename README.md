# AIO 2026 Learning Assistant

This repository contains the AIO 2026 Learning Assistant project.

## Project Structure

- `baseline/`: reference PDF RAG Chatbot version.
- `upgrade/`: improved implementation with modular RAG architecture.
- `docs/`: project planning, workflow, backlog and documentation.
- `tests/`: root-level smoke or cross-project tests.
- `others/`: local legacy/reference artifacts not required for the main project structure.

## Working Rule

Work on one backlog Task ID at a time. Technical improvements belong in `upgrade/`; documentation belongs in `docs/`; baseline changes require an explicit task.
